# MultilingualSentimentClassifier
Project completed to supplement MuckRack article exports where non-english results are classified as neutral, by manually classifying each one using HuggingFace transformers. This allowed for greater accuracy of reporting within the business. 

I installed the model and ran it locally to comply with my corporation's security requirements - data is not allowed to stream to the Internet in real time, therefore having the model able to run locally was my best option. 

This program creates an .xlsx output to match the file format of the pre-rated English language results.
